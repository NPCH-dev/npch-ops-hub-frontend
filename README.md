# NPCH Ops Hub — Frontend

NPCH Kontrollzentrum — Dashboard für das NobleProg AI Agent Team.

## Struktur

- `index.html` — Hauptdashboard (NPCH Kontrollzentrum)
- `agent-teams.html` — Agent Teams Übersicht
- `finance-agent.html` — Finance Agent Interface
- `finance-dashboard.html` — Finance Dashboard
- `sprint-dashboard.html` — Sprint Dashboard
